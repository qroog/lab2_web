## Weather App

Веб‑приложение для просмотра прогноза погоды по выбранным городам.

Ссылка: weatherapplab4.netlify.app

Видео: https://drive.google.com/file/d/1EvfCToc9zpNcnbnx46eXLsh9dbRSS7sz/view?usp=sharing

### Основные возможности

- Определение геолокации 
- Поиск городов с подсказками и выбором из выпадающего списка  
- Добавление нескольких городов и переключение между ними через вкладки  
- Отображение текущей погоды: температура, состояние, влажность, скорость ветра  
- Прогноз на несколько дней
- localStorage
- Адаптивный дизайн
